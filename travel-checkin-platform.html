Project Overview

项目概述

随着短视频与"打卡文化"的兴起,游客越来越倾向于记录并分享自己的旅行足迹。然而传统旅游平台内容同质化严重、推荐精准度不足,难以满足用户的个性化需求。本课题设计并实现了一个集景点浏览、旅行打卡、社区分享、个性化推荐、后台管理于一体的旅游打卡平台。

  • ✓前后端分离:Vue3 + Element Plus 构建 SPA 前端,Spring Boot 提供 RESTful API
  • ✓个性化推荐:基于用户的协同过滤(UserCF),挖掘用户打卡与评分行为
  • ✓高并发保障:Redis 缓存热点景点数据,JWT 无状态登录认证
  • ✓完整后台:景点/用户/动态/轮播图等内容可视化运营管理
📍 打卡 · 记录 · 分享让每一段旅程都有迹可循

Recommendation Algorithm

协同过滤推荐算法设计

系统采集用户的景点评分(1~5 分)与打卡行为(隐式反馈,计 4 分),构建"用户—景点"评分矩阵,采用基于用户的协同过滤(UserCF)实现个性化推荐。

①用户相似度 —— 余弦相似度

sim(u,v) = Σi∈Iuv ru,i · rv,i√Σ ru,i² · √Σ rv,i²

其中 Iuv 为用户 u 与 v 共同评分的景点集合,r 为评分值。相似度越高,两用户兴趣越接近。

②评分预测与 Top-N 生成

p(u,i) = r̄u + Σv∈S(u,K) sim(u,v) · (rv,i − r̄v)Σv∈S(u,K) |sim(u,v)|

选取与目标用户最相似的 K=20 个邻居用户,预测其对未打卡景点的评分,降序取前 N=10 个景点写入推荐表。

  1. 1
    行为数据采集

    显式:景点评分 1~5 分;隐式:打卡计 4 分、收藏计 4.5 分,融合为评分矩阵。

  2. 2
    构建评分矩阵

    以用户为行、景点为列构建稀疏矩阵 Rm×n,未交互项记为空。

  3. 3
    计算用户相似度

    两两用户基于共同评分项计算余弦相似度,得到用户相似度矩阵。

  4. 4
    邻居选取与评分预测

    取相似度 Top-K(K=20)邻居,加权平均预测目标用户对候选景点的评分。

  5. 5
    离线计算 + 缓存

    每日凌晨 @Scheduled 定时任务批量计算,Top-N 结果写入 Redis,接口毫秒级响应。

  6. 6
    冷启动兜底

    新用户行为不足时,降级为"热门景点 + 同城市热门"混合推荐,缓解冷启动问题。

数据库设计

MySQL 8 共设计 12 张数据表,核心表结构如下(主键均为自增 id,统一包含 create_time / update_time 审计字段)。

表名说明核心字段关联关系
user用户表平台注册用户username, password(BCrypt), nickname, avatar, gender, city, bio1-N → check_in / moment / score
scenic_spot景点表景点基础信息name, category_id, city, address, lng, lat, cover, intro, avg_score, heatN-1 → category;1-N → check_in
check_in打卡表用户打卡记录user_id, spot_id, content, images, check_time, lng, latN-1 → user / scenic_spot
spot_score评分表用户对景点评分user_id, spot_id, score(1~5)推荐算法核心数据源
moment动态表社区旅行动态user_id, spot_id, content, images, like_count, status(审核)1-N → comment / like
recommend_result推荐表UserCF 离线计算结果user_id, spot_id, predict_score, rank_no, calc_time定时任务写入 / Redis 同步缓存

Development Roadmap

设计与实现流程

按照软件工程规范完成从需求分析到系统测试的全过程。

01 需求分析

可行性研究与用例建模

调研旅游社交平台现状,绘制用例图与功能结构图,明确个性化推荐核心需求。

02 系统设计

架构设计 · 数据库设计 · 算法设计

确定前后端分离架构,完成 ER 图与表结构设计,选定 UserCF 算法并设计离线计算流程。

03 编码实现

04 系统测试

Postman 接口测试、边界用例功能测试;以准确率/召回率评估推荐效果并调参(K、N)。
